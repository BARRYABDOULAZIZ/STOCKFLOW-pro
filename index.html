          Export

          Excel et JSON contiennent tout (produits, factures, mouvements). Le CSV exporte le catalogue produits, format le plus courant pour un tableur simple.

          Import JSON

          Réimporte un fichier exporté depuis cette application (ou compatible). Les éléments avec le même identifiant seront remplacés, les autres ajoutés — rien n'est supprimé automatiquement.

          Sauvegarde locale

          Une copie de secours est enregistrée automatiquement dans ce navigateur à chaque changement. Elle reste sur cet appareil — elle ne remplace pas l'export JSON si tu changes d'appareil ou vides le cache.
